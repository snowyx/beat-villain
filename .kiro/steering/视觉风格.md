# 视觉风格 · 港式霓虹纸扎风（供每轮实现自动遵守）

> 本文件为 Kiro Steering，**每一轮前端实现都须自动遵守**。依据 `design.md` §9 与 `requirements.md` 需求 9。
> 基调：港式夜市灯牌 × 纸扎香烛 × 霓虹辉光；375px 竖屏小程序骨相；卡通、无血腥（见 `民俗合规.md`）。

---

## 1. 配色变量（CSS custom properties）

在 `app/css/theme.css` 的 `:root` 定义以下四个变量，全站引用变量而非写死色值：

```css
:root {
  --zhu-sha-red: #E23A3A;  /* 朱砂红：主色、按钮、符咒边（绝不用于表现血，见民俗合规） */
  --liu-jin-gold: #F4C430; /* 鎏金黄：标题、描边、纸钱 */
  --neon-purple: #A24BFF;  /* 霓虹紫：发光点缀、辅助 */
  --ink: #140A1F;          /* 夜市暗底：深色背景 */
}
```

四个十六进制值为锁定值，不得更改：朱砂红 `#E23A3A`、鎏金黄 `#F4C430`、霓虹紫 `#A24BFF`、墨底 `#140A1F`。

---

## 2. 霓虹辉光做法

- **文字霓虹**：关键标题用多层 `text-shadow`（内白外彩），紫/金描边模拟灯牌辉光。例：
  ```css
  text-shadow:
    0 0 2px #fff,
    0 0 8px var(--liu-jin-gold),
    0 0 16px var(--zhu-sha-red),
    0 0 28px var(--neon-purple);
  ```
- **按钮/边框霓虹**：用多层 `box-shadow`（内发光 `inset` + 外发光）表现霓虹管边框。
- **辉光呼吸**：可加极缓的 `@keyframes glow` 呼吸动画，但**仅对少量关键元素使用**（性能考虑），不要全局滥用。

---

## 3. 港式招牌楷体栈

- 标题/招牌字首选系统楷体栈，**不内嵌大字体文件**（保持纯静态轻量）：
  ```css
  font-family: "STKaiti", "KaiTi", "BiauKai", "楷体", serif;
  ```
- 标题可叠加金色描边 + 红底牌匾样式，模拟港式灯牌招牌（「敕令」式牌匾）。

---

## 4. 375px 竖屏小程序骨相

- 根容器固定 `max-width: 375px` 居中，`min-height: 100dvh`，整体竖排布局。
- 小程序骨相：竖屏单页、底部保留 **tab 感操作条**（当前流程态的主按钮区）、可分享卡片样式。
- 卡片用圆角 + 金边 + 轻微纸纹（CSS 渐变模拟纸扎质感）。

---

## 5. 纸扎 / 香烛元素

- 用 **Emoji + canvas 组合**，避免大量位图资产：🧧 🕯️ 🔥 作点缀装饰；小人、纸钱、分享图用 canvas 2D 绘制。
- 小人严格为卡通纸片人、化灰只用祥云消散（见 `民俗合规.md`，无血腥）。

---

## 6. 响应式与横屏提示

- 以 375 为基准，用 `clamp()` / `vw` 适配更宽屏（居中留白），**竖屏优先**。
- 横屏时给出轻提示「建议竖屏」，不阻断流程。
